## 진행 순서

2. **데이터 입력:** 소스 이용조건·허용 방식 관리, CSV 검증, 중복 차단, 팀·선수 매핑, UTC 저장·한국시간 표시를 구현합니다. 축구 API 연결은 현재 이용조건과 무료 범위를 확인한 뒤 추가합니다.
3. **규칙과 예측 이력:** 1X2·핸디캡·언더오버 등 검토된 규칙의 경계값을 확인하고, 입력과 시장 버전에 연결된 불변 예측 스냅샷을 저장합니다. 검증 전 출력은 운영 예측으로 활성화하지 않습니다.
4. **모델과 시간순 검증:** 전 종목 모델 인터페이스를 마련하고, 실제 확보한 데이터에 맞춰 종목별 후보를 구현합니다. 데이터가 먼저 확보되는 종목부터 평가하며, 다른 종목의 카탈로그와 미완료 상태도 유지합니다. 누수 검사와 기준 모델 비교를 통과한 범위부터 활성화합니다.

첫 구현의 완료 기준은 전 종목을 등록하고, CSV를 검증하여 가져오며, 규칙과 데이터가 부족한 항목의 보류 이유를 로컬 화면에서 확인할 수 있는 것입니다. 확률 제공은 실제 데이터와 모델 검증을 확보한 후 별도 단계에서 완료합니다.

## 협업과 푸시

각 에이전트는 별도 worktree와 `codex/<작업명>` 브랜치를 사용합니다. 통합 담당 한 명이 검증된 커밋을 main에 모읍니다. 커밋은 의미 있는 작업 단위로 자동 생성합니다.

작성자에 관계없이 main에 통합된 미푸시 커밋 **20개마다** 원격 main으로 푸시합니다. 1~19개는 로컬에 보관하며, 작업 종료 때문에 조기 푸시하지 않습니다. 초기 문서 커밋도 첫 20개에 포함합니다. 상세한 집계·동시 작업·실패 처리 규칙은 AGENTS.md에 있습니다.
