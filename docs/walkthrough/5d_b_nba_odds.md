# 5d-b. NBA 배당: 하루 한 번, 승패 2지선다

작성: 2026-10-22. 상태: **완료.** 첫 실제 수집에서 다가올 41경기 모두 연결, 배당 712행, 1크레딧.

## 한 줄 요약

The Odds API의 `basketball_nba`에서 다가올 NBA 경기의 승패 배당을 받습니다. NBA는 거의 매일 경기가 있어 축구처럼 경기 시각마다 받으면 무료 예산(월 500크레딧)을 넘기 때문에, **그날 첫 경기 1시간 전에 한 번만**(1크레딧) 받습니다. 한 번의 응답에 다가올 경기 전체가 들어 있어 그날 늦은 경기와 다음 날 경기도 함께 받습니다. 배당은 NBA 경기 표(`silver.games`)를 가리키는 별도 표 `silver.game_odds_revisions`에 버전으로 쌓습니다.

## 크레딧 예산

| 대상 | 받는 때 | 월 추정 |
|---|---|---|
| 축구 다섯 리그(5b) | 경기 시각 묶음마다 24·1시간 전 | 약 300 |
| NBA(5d-b) | 미국 동부 날짜별 첫 경기 1시간 전 하루 1번 | 약 30(정규 시즌·플레이오프 월 25~31일) |
| 합계 |  | 약 330 / 500 |

- 남은 크레딧이 60 아래면 NBA는 받지 않습니다(축구 우선, `LOW_CREDITS`).
- 90분 안에 받은 적이 있으면 다시 받지 않습니다.
- 경기 일정 확인(`/events`)은 무료라 30분마다 봅니다.

**대가:** 그날 늦은 경기(예: 서부 02:30 UTC)는 시작 약 4시간 전 배당, 다음 날 경기는 약 25시간 전 배당이 됩니다. 경기 직전 배당(부상 소식 반영)이 필요하면 하루 2번(크레딧 약 60)으로 늘릴 수 있습니다.

## 경기 연결: 시작 시각이 10분 다르다

두 소스의 시작 시각이 정확히 같지 않습니다. 첫 수집 41경기 중 36경기는 The Odds API가 10분 늦고(예: balldontlie 23:00, The Odds API 23:10), 5경기는 같았습니다. 그래서 "같은 홈·원정 + 시작 시각 3시간 안"으로 연결합니다. 같은 대진이 한 시즌에 여러 번 열리지만 3시간 안에 두 번 열리지는 않습니다. 후보가 둘 이상이면 `MATCH_AMBIGUOUS`, 없으면 `MATCH_NOT_FOUND`로 남기고 버리지 않습니다.

## 사용한 기술

| 기술 | 어디에 | 어떻게 썼나 |
|---|---|---|
| REST API(무료 `/events` → 유료 `/odds`) | `run_due` | 무료 일정으로 시점을 판단하고, 필요할 때만 1크레딧 요청 |
| `zoneinfo`(America/New_York) | `slate_first_tips` | UTC 시작 시각을 미국 동부 날짜로 묶어 "그날 첫 경기"를 찾음(02:30 UTC 경기는 동부 기준 전날 밤) |
| 응답 헤더 기반 예산 | `x-requests-remaining`, `RESERVE_CREDITS` | 크레딧이 모자라면 NBA를 건너뜀 |
| Postgres 임시 테이블 + `COPY` + `DISTINCT ON` | `write_odds` | 받은 배당을 한 번에 넣고, 키별 최신 버전과 값이 다른 것만 새 버전으로 추가 |
| 시간 범위 조인 | `find_game` | `tipoff_utc BETWEEN 시작 − 3시간 AND 시작 + 3시간` |
| SQL 함수 | `silver.game_odds_known_at(as_of)` | 기준 시각에 알려진 배당. `published_at`(북메이커가 값을 바꾼 시각)과 `received_at`을 모두 봄 |
| `difflib` 이름 유사도 | `suggest_aliases` | 대조표 후보를 만들고 사람이 검토 |
| Airflow 병렬 작업(`[a, b] >> c`) | DAG | 축구·NBA 배당을 따로 받고 둘 다 끝나면(`all_done`) 스냅샷 |
| SeaweedFS(S3) | Bronze `the-odds-api/nba/날짜/sha256=…json` | 받은 응답 보존 |

## 면접에서 나올 만한 질문

**Q. 무료 한도가 월 500인데 NBA를 어떻게 넣었나요?**
요청 한 번이 리그의 다가올 경기 전체를 돌려준다는 점을 이용했습니다. NBA는 하루 경기가 저녁에 몰려 있어서, 그날 첫 경기 1시간 전에 한 번 받으면 그날 경기와 다음 날 경기가 모두 들어옵니다. 하루 1크레딧, 월 약 30입니다. 대신 늦은 경기는 몇 시간 전 배당이라는 대가를 문서에 적었고, 필요하면 하루 2번으로 바꿀 수 있습니다.

**Q. 두 소스의 경기를 어떻게 같은 경기로 판단하나요?**
팀 이름은 검토한 대조표로만 바꾸고, 같은 홈·원정이면서 시작 시각이 3시간 안이면 같은 경기로 봅니다. 실제로 두 소스의 시작 시각이 10분씩 달라서, 정확히 같은 시각을 요구했다면 41경기 중 36경기를 놓쳤을 것입니다.

## 한계

- **과거 NBA 배당이 없습니다.** 무료로 구할 곳이 없어, 시장과의 비교는 앞으로 쌓이는 경기 전 배당으로만 할 수 있습니다(5d-c 모델 평가는 단순 비율 등 기준선과 비교).
- **늦은 경기 배당은 몇 시간 전 값입니다**(위 예산 절).
