# 5d-c. NBA 모델: 점수 차 등급과 Elo

작성: 2026-10-22. 자동 생성 보고서: [NBA 평가 보고서](../reports/evaluation_nba.md)

## 한 줄 요약

무승부가 없는 NBA 승패 예측 모델 세 가지(단순 비율, 점수 차 등급, Elo)와 연전(back-to-back) 효과를 축구와 같은 규칙으로 백테스트·평가했습니다. 시험 시즌(2023-24 이후 3,965경기)에서 팀 전력 모델은 단순 비율보다 로그 손실이 **0.078 낮고**(95% 구간 [−0.088, −0.067]), 확률 보정 오차도 기준(0.03) 안입니다. 그래도 **시장 배당과 비교할 과거 자료가 없어 NOT_VALIDATED**이고, 예측은 WITHHELD입니다.

## 모델

| 모델 | 방식 | 고른 설정(검증 2021-22·2022-23) |
|---|---|---|
| 단순 비율 | 학습 기간 홈 승 비율 | — |
| 점수 차 등급 | 점수 차 = 홈 이점 + 홈 팀 등급 − 원정 팀 등급 + 잡음. 시간 감쇠 가중 ridge 최소제곱, 홈 승 확률 = Φ(예상 점수 차 / σ) | ridge 3, 반감기 90일(24개 후보) |
| 점수 차 등급+연전 | 위에 "전날도 경기를 했는가"(일정은 미리 공개) 효과 하나 추가 | 같은 설정 + 연전 |
| Elo | 경기마다 등급 갱신, 점수 차 배수, 새 시즌에 평균으로 일부 되돌림 | K 15, 홈 50, 회귀 0.5(60개 후보) |

축구의 Poisson이 "득점"을 모델링했다면 NBA는 득점이 많아(경기당 약 230점) 점수 **차**가 정규분포에 가깝습니다. 그래서 점수 차 회귀가 자연스러운 출발점입니다.

학습된 값(전체 자료, 점수 차 등급+연전): 홈 이점 **약 2점**(2018-19 홈 승률 0.593에서 최근 0.54~0.55로 줄어든 것과 맞음), 연전 불이익 **약 2.2~2.6점**, 잔차 표준편차 σ 약 14점. 2023-24 시즌 끝 등급 1위는 보스턴(그해 우승), 2025-26 끝은 오클라호마시티·샌안토니오·뉴욕 순.

## 결과를 어떻게 읽나

- **축구보다 예측하기 쉽습니다.** 무승부가 없고 전력 차가 결과에 더 잘 드러납니다(적중률 67%).
- **보정은 기준을 통과합니다.** 축구 모델들은 ECE 기준(0.03)도 자주 못 넘었는데 NBA는 모두 넘었습니다. 남은 사유는 시장 비교 하나입니다.
- **연전 효과는 실제로 있지만 작습니다.** 계수는 약 2점으로 뚜렷하지만, 연전 경기가 전체의 28%뿐이고 효과가 작아 로그 손실 개선은 통계적으로 확실하지 않습니다.
- **포스트시즌이 더 어렵습니다**(0.640 vs 정규 0.607). 맞붙는 팀의 전력이 비슷하기 때문입니다.
- **시즌 초반이 조금 더 어렵습니다**(0.622 vs 0.607). 지난 시즌 등급을 쓰는데 선수 이동이 반영되지 않습니다.
- **시장보다 나은지는 모릅니다.** 같은 경기의 과거 배당이 없어 비교하지 못했고, 앞으로 쌓이는 경기 전 배당(5d-b)으로 비교합니다.

## 사용한 기술

| 기술 | 어디에 | 어떻게 썼나 |
|---|---|---|
| numpy 가중 ridge 최소제곱 | `MarginRatingModel.fit` | (XᵀWX + Λ)β = XᵀWy를 `np.linalg.solve`로. W는 반감기 감쇠, Λ는 팀 등급에만 강한 벌점 |
| 정규분포 누적확률 `math.erf` | `_phi` | 예상 점수 차 / σ → 홈 승 확률(scipy 없이) |
| Elo 온라인 갱신 | `EloModel` | 학습 경기가 앞에서부터 늘어나기만 하므로 같은 인스턴스에 이어서 넣음(블록마다 처음부터 다시 계산하지 않음) |
| 시간순 walk-forward | `nba_backtest.walk_forward` | ISO 주 블록, `bisect`로 "시작 + 4시간 ≤ 블록 시작"인 경기만 학습 |
| 격자 탐색 | `candidates` | 검증 로그 손실로 고르고 시험은 한 번만. 첫 실행에서 격자 끝이 골라져 넓힌 뒤 다시 실행(아래) |
| 블록 부트스트랩·Wilson 구간 | `evaluation.block_bootstrap`, `wilson` 재사용 | 축구와 같은 함수로 차이의 95% 구간과 보정 구간 |
| Postgres CHECK | `015_game_backtests.sql` | 학습 마지막 경기 + 4시간 ≤ fit_cutoff ≤ 시작 시각, 확률은 0~1 사이, 결과는 HOME·AWAY만 |
| `COPY` | `store_run` | 예측 24만 행을 한 번에 저장 |
| 실행 기록 표 재사용 | `modeling.backtest_runs`(`competition_code = 'nba'`) | 축구와 같은 구분 키로 같은 실행을 두 번 저장하지 않음 |

## 면접에서 나올 만한 질문

**Q. 축구와 NBA에 다른 모델을 쓴 이유는?**
축구는 득점이 적고(경기당 약 2.8골) 무승부가 많아 득점 수를 Poisson으로 모델링합니다. NBA는 득점이 많아 점수 차가 정규분포에 가깝고 무승부가 없습니다. 그래서 점수 차 회귀 + 정규분포 확률을 썼습니다. 평가 규칙(시간순 학습, 검증·시험 분리, 블록 부트스트랩, 검증 기준)은 같게 유지해 두 종목 결과를 같은 잣대로 비교할 수 있게 했습니다.

**Q. 검증에서 고른 값이 후보 범위 끝이면 어떻게 하나요?**
범위 밖에 더 좋은 값이 있을 수 있으니 범위를 넓혀 다시 고릅니다. 이번에는 넓혀도 같은 값이 골라져 안쪽 최적임을 확인했습니다. 다만 첫 실행 때 시험 결과도 출력됐기 때문에, 시험을 본 횟수를 문서에 공개했습니다. 시험 결과를 보고 설정을 바꾸지는 않았습니다.

**Q. 연전 효과가 있는데 왜 "확실하지 않다"고 하나요?**
계수(약 2점)는 뚜렷하지만, 평가하는 것은 확률의 정확도입니다. 연전 경기가 전체의 28%이고 2점은 σ 14점에 비해 작아서, 로그 손실 개선(−0.002)의 95% 구간이 0을 포함합니다. "효과가 있다"와 "예측이 확실히 좋아진다"는 다른 질문입니다.

## 한계

- **시장 비교가 없습니다.** 과거 NBA 배당이 없어서 검증 기준의 핵심을 판단할 수 없습니다. 5d-b부터 쌓는 경기 전 배당으로 비교합니다.
- **선수 정보가 없습니다.** 부상·휴식(load management)·트레이드를 모릅니다. NBA는 한 선수의 비중이 커서 시장이 이 정보로 크게 앞설 가능성이 높습니다.
- **플레이인·NBA컵·해외 경기를 따로 다루지 않습니다.** 라스베이거스 NBA컵 준결승·결승과 해외 경기는 실제로는 중립인데 홈 경기로 계산합니다(시즌당 몇 경기).
- **경기 전 예측 기록·알림은 아직 없습니다**(5d-d).
