경기 결과 예측보다 먼저, 예측에 쓰는 데이터를 믿을 수 있게 만드는 데이터 엔지니어링 프로젝트

01 WHY

왜 시작했나

🎯 시작한 계기

스포츠 경기를 데이터로 직접 예측해 보고 싶었고, 데이터 엔지니어로서 수집부터 검증까지 전 과정을 실제 문제로 다뤄 보고 싶었습니다. 막상 시작하니 모델보다 먼저 부딪힌 건 데이터였습니다.

문제 1미래 정보가 섞인다

경기 후에 갱신된 기록이나 마감 직전 배당이 학습에 섞이면, 백테스트 성능이 실제보다 좋아 보입니다.

문제 2데이터는 계속 바뀐다

일정 변경, 기록 정정, 늦은 입력이 흔합니다. 값을 덮어쓰면 "그때 무엇을 알았는지" 다시 재현할 수 없습니다.

문제 3출처마다 쓸 수 있는 범위가 다르다

무료 데이터라도 저장·학습·재배포 허용 범위가 제각각입니다.

그래서 모델보다 데이터 기반을 먼저 만들었습니다. 모든 자료에 발표 시각과 입력 시각을 남기고, 덮어쓰지 않고 버전으로 쌓아, 어느 시점이든 그때의 입력을 그대로 재현할 수 있게 합니다.

03 GOAL

최종 목표

경기 마감 전에, 그때 알 수 있던 데이터로만 계산한 확률을 남기고 실제 결과로 검증하는 예측 플랫폼
재현 가능한 예측모든 예측을 기준 시각·데이터 버전과 함께 저장. 같은 입력이면 같은 결과
숫자로 하는 검증시간순 백테스트로 기준 모델·시장 배당과 비교 (Log loss, Brier score)
검증된 확률만 제공데이터나 검증이 부족하면 추측하지 않고 보류 이유를 표시
매주 자동 분석일정·배당·결과가 들어오면 분 단위로 갱신, 휴대폰에서 확인
