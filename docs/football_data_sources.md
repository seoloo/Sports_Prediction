# 해외축구 데이터 소스 검토 v1

검토일: 2026-10-20(KST). 공개된 약관·안내 페이지를 읽고 정리한 기록입니다. 법률 자문이 아니며, 문구가 모호한 항목은 보수적으로 해석했습니다. 이 문서는 사용 후보를 정리할 뿐 앱의 소스를 자동으로 활성화하지 않습니다. 실제 활성화는 사용자가 소스 화면에서 근거를 입력해 승인합니다.

## 소스별 세부

### openfootball/football.json

- 저장소의 LICENSE.md가 CC0 1.0이며 "제한 없이 사용"을 명시합니다. 원본 JSON을 저장소 테스트 샘플로 포함해도 됩니다.
- 2026-10-20에 2024-25·2025-26 EPL 파일을 내려받아 확인했습니다. 각 380경기이며 date, time, team1, team2와 score를 가집니다.
- 데이터 품질 주의:
  - score가 `{"ht":[..],"ft":[..]}` 객체인 경기와 `[0,0]` 배열인 경기가 섞여 있습니다. 2025-26 EPL에서 ht가 있는 경기는 353/380입니다. 수집 단계에서 형식 차이를 명시적으로 처리하고 전반 점수 결측을 0으로 바꾸지 않습니다.
  - time에 시간대가 없습니다. 리그 현지 시간(EPL은 Europe/London)으로 해석하되 가정임을 표시합니다.
  - published_at이 없습니다. 실제 확보 시각(received_at)만 기록하며, 과거 시점 재구성에는 아래의 HISTORICAL_RECONSTRUCTION 규칙을 따릅니다.
  - 원본 Football.TXT 갱신이 늦을 수 있고 정확성 보장이 없습니다. 같은 경기의 값 변경은 새 결과 버전으로 저장합니다.
  - 팀 이름(예: "Manchester United FC")은 다른 소스와 다르므로 별칭 매핑이 필요합니다.

### football-data.co.uk

- 확인 문구: 이용은 "private individuals only"를 대상으로 하며, 모든 데이터는 "league match prediction" 목적으로 제공된다고 안내합니다. 상업 상품이나 자동 봇·스크레이퍼·AI를 사용하는 데이터 학습 상품에는 쓰지 말라고 명시합니다.
- 해석과 적용:
  - 개인이 리그 경기 예측에 쓰는 것은 명시된 목적에 맞습니다.
  - 자동 다운로드 금지로 해석해, 사용자가 CSV를 직접 내려받아 `data/landing/football-data-co-uk/`에 두면 파이프라인이 그 폴더에서 가져오게 합니다. 사이트를 크롤링하는 코드는 만들지 않습니다.
  - 재배포 조항은 없지만 CSV를 Git에 포함하지 않습니다. 공개 포트폴리오에는 코드와 집계 지표만 공개하고, 원본·경기별 배당은 공개하지 않습니다.
  - 모호한 부분(스크립트 다운로드 가능 여부, 집계 백테스트 지표 공개)은 사이트가 안내하는 연락처로 문의해 확인하는 것을 권장합니다. 확인 전에는 위의 보수적 방식을 유지합니다.
- 데이터 주의: Pinnacle 배당은 2025-07-23 이후 갱신이 늦어 사용에 주의하라는 안내가 있고 시장 평균·최대 배당에서도 제외되었습니다. 해당 기간 이후 기준선은 시장 평균 배당을 사용하고 Pinnacle 값은 별도 표시합니다.

### football-data.org API

- 무료 12개 대회: Champions League, Primeira Liga, Premier League, Eredivisie, Bundesliga, Ligue 1, Serie A, La Liga, Championship, Brasileirão Série A, World Cup, European Championship.
- 등록 사용자 분당 10회, 미등록은 하루 100회이며 목록 자원만 조회 가능합니다.
- 등록 약관 확인 사항: 앱·웹사이트에 "Football data provided by the Football-Data.org API" 표기, 오픈소스 저장소에 키 저장 금지, 해지 시 계정과 저장 데이터 삭제 및 이후 데이터 참조 금지, 팀 로고 등은 별도 저작권.
- 적용: 사용자가 직접 계정을 만들고 약관에 동의해야 합니다. 키는 `.env`(Git 제외)에만 둡니다. 화면과 README에 출처를 표기합니다. 분당 10회 이하로 요청하고 429 응답 시 대기합니다.

### StatsBomb Open Data

- 사용자 계약(2023-09-08 갱신본) 확인 사항: 분석·연구와 이해 공유 목적의 접근을 허용합니다. 데이터의 제3자 제공·재배포와 데이터 또는 파생 분석의 상업적 이용을 금지합니다. 공개 분석에는 StatsBomb 로고를 표기해야 하며 이용 전 이름·이메일 등록을 요청합니다.
- 이 구분은 앱의 목적별 사용권(training_features와 그 외 목적)으로 관리합니다.

## 시점 처리 규칙

- 운영 예측(PROSPECTIVE): 실제로 확보한 received_at과 발표 시각이 as_of 이하인 자료만 사용합니다.
- 과거 재구성(HISTORICAL_RECONSTRUCTION): 과거 시즌 결과는 발표 시각을 모르므로, 경기 개시 시각 + 3시간을 "알려진 시각"으로 가정하고 `availability_assumed`로 표시합니다. 이 가정은 백테스트에만 쓰고 운영 성능과 따로 보고합니다.
- 과거 배당은 소스가 제공하는 마감 배당입니다. 마감 배당은 경기 직전 정보를 포함하므로 같은 시점의 모델 입력에는 넣지 않고 비교 기준선으로만 사용합니다.

## 첫 대상 범위

1. EPL(openfootball `en.1`, football-data.co.uk `E0`)부터 시작합니다.
2. 파이프라인과 검증이 안정되면 라리가, 분데스리가, 세리에A, 리그1로 넓힙니다. 세 소스 모두 이 다섯 리그를 포함합니다.
